WatchNotes Privacy Policy

HomeEnglish繁體中文

Effective date: 2026-09-18

Summary

WatchNotes is a browser extension that lets an AI (Google Gemini) watch the YouTube video you are viewing and write notes with you. The developer runs no server and collects nothing. Your settings and notes stay in your browser. The only data that leaves your computer is what the extension sends to Google's Gemini API, using the API key you supply, to answer your requests.

What is stored, and where

DataWhere it is kept
Your Gemini API key and settings (languages, model, custom prompts, Obsidian vault name)Your browser only (chrome.storage.local). Not synced, not uploaded.
Notes for each video (AI notes, your questions and the answers, your own notes) and cached captionsYour browser only (chrome.storage.local).
The notes folder you choose (optional)A folder handle kept in your browser (IndexedDB). Notes are written as Markdown files into that folder on your computer.
Downloaded notesYour Downloads folder, only when you press Download.

What is sent, and to whom

Only when you start notes, ask a question, or ask again after a conversation expires, the extension sends a request directly from your browser to Google's Gemini API (generativelanguage.googleapis.com) with your own API key. A request can contain:

  • the YouTube video URL (Google fetches the video itself; the extension does not download it),
  • the video's captions, in caption mode,
  • your question, the instructions (prompts), and, when an expired conversation is resumed, your earlier notes for that video.

How Google handles this data is governed by Google's terms for the Gemini API. On the free tier Google may use submitted content to improve its products; on a paid tier it does not. See the Gemini API Additional Terms of Service.

To read the video title, the current playback time and captions, the extension talks to the YouTube page you already have open (youtube.com). Nothing else is contacted.

What we do not do

  • No analytics, tracking, advertising, or telemetry.
  • No developer server; the developer never receives your API key, notes, questions, or browsing activity.
  • No selling or sharing of data with anyone.
  • No remote code: everything the extension runs ships inside the extension package.

Your control

  • Delete your API key or change any setting on the extension's settings page.
  • Remove the notes folder link with Disconnect on the settings page. Files already written stay in your folder.
  • Removing the extension deletes everything it stored in the browser.
  • Delete or revoke your API key at aistudio.google.com/apikey.

繁體中文摘要

WatchNotes 是一個瀏覽器擴充套件，讓 AI（Google Gemini）陪你看正在播放的 YouTube 影片並寫筆記。開發者沒有任何伺服器，也不蒐集任何資料。你的設定與筆記只存在你的瀏覽器裡。唯一離開你電腦的資料，是擴充套件用你自己的 API key、直接送給 Google Gemini API 的請求。

儲存了什麼、存在哪裡

  • Gemini API key 與各項設定：只存在瀏覽器本機（chrome.storage.local），不同步、不上傳。
  • 每部影片的筆記（AI 筆記、你的問題與回答、你自己的想法）與字幕快取：只存在瀏覽器本機。
  • 你選的筆記資料夾（選填）：瀏覽器只保存資料夾的存取權（IndexedDB），筆記以 Markdown 檔寫進你電腦上的那個資料夾。
  • 下載的筆記：只有按下載時才存到你的「下載」資料夾。

送出了什麼、送給誰

只有在你開始產生筆記、提問，或對話過期後再次提問時，擴充套件才會從你的瀏覽器直接呼叫 Google Gemini API（generativelanguage.googleapis.com），使用你自己的 API key。內容可能包含：YouTube 影片網址（影片由 Google 自行讀取，擴充套件不下載影片）、字幕模式下的字幕文字、你的問題與指令，以及接續過期對話時這部影片先前的筆記。

Google 如何處理這些資料依 Gemini API 條款而定：免費層送出的內容可能被 Google 用於改進產品，付費層則不會。請參考 Gemini API 附加服務條款。

為了讀取影片標題、播放時間與字幕，擴充套件只會和你已經開啟的 YouTube 頁面（youtube.com）溝通，不會連到其他地方。

我們不做的事

  • 沒有任何分析、追蹤、廣告或遙測。
  • 沒有開發者伺服器，開發者收不到你的 API key、筆記、問題或瀏覽紀錄。
  • 不販售、不分享任何資料。
  • 不載入遠端程式碼，執行的程式全部包含在擴充套件裡。

你可以控制的

  • 在設定頁刪除 API key 或修改任何設定；按「取消連結」移除資料夾連結（已寫入的檔案會留在你的資料夾）。
  • 移除擴充套件會刪除它在瀏覽器裡存的所有資料。
  • 到 aistudio.google.com/apikey 刪除或停用你的 API key。
